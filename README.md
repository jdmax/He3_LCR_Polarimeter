# He3 LCR Polarimeter Software
LabView instrumentation software for a liquid crystal retarder based 3He polarimeter. 

Main program is PS_Main.vi. Files with PS prefix are related VIs, while other are temporary utilities and tests.

Hardware is covered in: https://doi.org/10.1016/j.nima.2014.07.049
